# YouTube Thumbnail Image Generator

Прочитать `meta/thumbnails.md`. Существующие пользовательские изображения не
перезаписывать.

- Если предоставлены face/brand references, использовать только их.
- Если references нет, сделать безличную композицию без имитации автора.
- Создать реально разные A/B/C, а не цветовые вариации одного изображения.
- Проверить читаемость в маленьком размере, отсутствие обрезки и ложных деталей.
- Экспортировать PNG/JPEG до 2 MB в `thumbnails/thumb_A.*`,
  `thumb_B.*`, `thumb_C.*`.

Если качественно разные B/C получить нельзя, вернуть честный receipt для
title-only A/B/C вместо дубликатов.
