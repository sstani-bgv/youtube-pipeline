# YouTube Description Writer

Собрать описание в порядке:

1. первые 1–2 строки: ценность видео и CTA;
2. короткое содержание;
3. chapters только по проверенным таймкодам;
4. пользовательские ссылки;
5. обязательные disclosures, если они нужны.

Не придумывать ссылки, таймкоды, контакты, партнёрства или лид-магниты.
Максимум 5000 UTF-8 байт, без `<` и `>`.

Сохранить итоговый body в fenced-блоке `meta/description.md`, чтобы uploader мог
прочитать только готовый текст без служебных комментариев.
