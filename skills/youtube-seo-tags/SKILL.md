# YouTube SEO Tags

Сформировать 15–20 тегов четырёх типов:

- точная тема;
- смежные поисковые формулировки;
- сущности, продукты и имена, реально упомянутые в видео;
- частые варианты написания и опечатки.

Не вызывать платные SEO-сервисы без просьбы пользователя. Не добавлять
нерелевантные high-volume слова. Суммарный API-budget тегов — максимум 500
символов с учётом запятых и кавычек вокруг тегов с пробелами.

Сохранить человекочитаемый список и готовый JSON-массив в `meta/tags.md`.
