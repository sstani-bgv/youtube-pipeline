# Общий glossary

Хранить здесь только универсальные термины, которые полезны большинству
пользователей. Не добавлять личные имена, названия закрытых проектов, клиентов,
каналов и внутренние факты.

Контекст проекта и пользовательский glossary важнее этой таблицы.

| Распознано | Исправить на | Основание |

| гит хаб | GitHub | название продукта |

При сомнении не заменять автоматически.
