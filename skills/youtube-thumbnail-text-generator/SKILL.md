# YouTube Thumbnail Text Generator

Для A/B/C выбрать три разные визуальные гипотезы: результат, конфликт,
демонстрация, объект, эмоция или до/после.

Для каждой сохранить:

- цель гипотезы;
- экранный текст 0–5 слов;
- главный объект;
- композицию и контраст;
- связь с соответствующим title;
- запрещённые элементы и риск misleading.

Не использовать лицо конкретного человека без предоставленного reference image.
Не выдавать concept-art за доказательство. Сохранить в `meta/thumbnails.md`.
