# media/ — что положить сюда

`index.html` ссылается на эти файлы. Сгенерируй их из сырья с помощью `ffmpeg`
по production flow из `../../PRODUCTION.md` и положи рядом:

| Файл | Что | Рецепт (кратко) |
|---|---|---|
| `base.mp4` | базовый клип говорящей головы, 9:16, 1080×1920, без звука, длина = `data-duration` | A3: центрированный кроп `crop=405:720:437:0` → `scale=1080:1920` |
| `tile1.jpg … tile6.jpg` | 6 тайлов 3:4 для split-screen грида (вторичный контент) | A4: `crop=540:720:370:0` → `scale=360:480` из разных таймкодов |
| `phone.jpg` | стилл 9:16 в телефон-мокап | A4: `crop=405:720:437:0` → `scale=400:711` |
| `card.jpg` | стилл 9:16 в плавающую карточку-полароид | A4: `crop=405:720:437:0` → `scale=360:640` |

Пути в `index.html` относительные (`media/...`) — имена менять можно, но синхронно с разметкой.

Дальше: `hyperframes preview` → QA-проход из `../../QA.md` →
`hyperframes render . --quality high --output short-final.mp4`.
